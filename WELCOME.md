# Welcome to the HUI · H2O Public Commons

This Commons is a bounded public participation and co-creation surface for Humanity United International and the Humane Humanity Organization.

Start in the mode that fits what you want to do:

- **Learn:** read the README, contribution guide and governance boundary.
- **Contribute:** open the structured Public contribution form.
- **Build:** open or choose a bounded BUILD task and use the branch/fork + pull-request workflow.
- **Discuss:** use GitHub Discussions for public questions, deliberation and proposals; the issue-based `Agora 000` remains available as a launch-zero fallback.

Participation is intended to become increasingly reciprocal and capability-generating, while preserving the distinction between contribution, evidence, review, authority, ownership, publication and canon.

Do not post private, confidential, security-sensitive, rights-limited or regulated material in this public repository.
