# Security and Sensitive-Information Boundary

The HUI · H2O Public Commons is public. Treat everything posted here as potentially visible to anyone.

## Do not post publicly

- passwords, API keys, tokens, credentials or secrets;
- private personal data;
- confidential partner/customer/collaborator information;
- unpublished security topology;
- exploit details or vulnerability proof-of-concept material;
- unpublished protected HUI documents;
- rights-limited third-party files;
- regulated financial/tokenization details not cleared for publication.

## Vulnerability reports

Do not disclose a suspected vulnerability in a public issue or discussion.

Until a dedicated private security-reporting channel is activated and published, stop before posting exploit details and contact an authorized HUI/H2O maintainer through an already-established private channel.

A dedicated private reporting channel is a launch requirement before this repository is presented as accepting security reports.

## Public issue safety

If an issue contains sensitive information by mistake, maintainers may restrict/remove the content and preserve only the minimum audit record appropriate to the circumstances.
