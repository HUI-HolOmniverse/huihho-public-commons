# Launch-zero quick path

1. Read `README.md` and `GOVERNANCE_BOUNDARY.md`.
2. Choose **Public contribution** or **Build / improvement task** under Issues → New issue.
3. Use Discussions for public deliberation and questions.
4. For build work, connect an issue to a branch/fork and pull request.
5. Keep all material public-safe and rights-aware.

The Commons is opening as a real participation surface, but later HUI governance and stewardship states remain evidence-gated.
