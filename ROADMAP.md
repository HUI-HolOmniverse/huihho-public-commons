# Public Commons Roadmap — Launch Seed

## Launch-zero priorities

1. Make the public repository understandable to a first-time visitor.
2. Verify public contribution intake with provenance/rights/consent.
3. Verify a bounded BUILD issue -> branch/fork -> pull request -> review path.
4. Enable public deliberation through Discussions or a labeled issue-based Agora.
5. Link huihho.com `/contribute`, `/build`, `/participate`, and `/open-source` to the correct public destinations.
6. Verify public safety boundaries and private security reporting instructions.
7. Run desktop/mobile external readback.

## Good first contribution candidates

- improve plain-language explanations;
- test links and report broken routes;
- accessibility review;
- Portuguese translation seed;
- additional language translation proposals;
- documentation fixes;
- public-safe source/provenance references;
- UI/readability suggestions;
- small tests or readback scripts;
- issue-form usability feedback.

## Not launch-zero

The following remain separate evidence-gated capabilities and are not implied by this repository's existence:
- FUND payment rails;
- operational RUN permissions;
- MANAGE delegation;
- distributed legal/economic OWN mechanisms;
- CROWN / Crowd-Crowned status;
- regulated tokenization;
- unrestricted access to private HUI repositories or archives.
